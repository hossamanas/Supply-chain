📌 **Project Overview**  
This project focuses on analyzing Supply Chain data to monitor and evaluate business performance. The aim is to track financial metrics, inventory levels, and supplier efficiency.

🎯 **Objectives**  
• Monitor profit and revenue trends across quarters  
• Track stock-out and over-stock situations  
• Evaluate drop-off rates and class performance  
• Analyze average supplier delivery delays  

🛠️ **Tools Used**  
• Microsoft Excel • Power Query (for data cleaning & transformation) • Pivot Tables • Charts & Visualization  

🧹 **Data Cleaning Process**  
• Removed duplicate records • Handled missing or inconsistent values • Standardized date and currency formats • Transformed and structured data using Power Query  

💡 **Key Insights**  
• Half-year and quarterly financial comparisons • Inventory risk identification (stock levels) • Vendor performance and delay tracking
